# EP-08 concise recruitment-product benchmark

Reviewed 2026-11-27 using public official product documentation only. This is directional product evidence, not a claim of feature parity or permission to copy proprietary systems.

| Official reference | Market-standard signal | EP-08 decision |
|---|---|---|
| [Naukri AI REX](https://recruit.naukri.com/recruit/airex) | Mandate capture, candidate sourcing/screening, pipeline review, productivity insights and human recruiter feedback | Implement transparent deterministic matching, structured pipelines and analytics now; defer outreach agents, calls and AI screening. |
| [LinkedIn Recruiter features](https://business.linkedin.com/talent-solutions/recruiter/recruiter-features/d) | Shared projects, pipeline stages, conversion statistics, activity history, notifications and collaboration | Implement tenant vacancy dashboards, immutable events, assignment controls and conversion metrics without broad administrator access. |
| [Indeed Smart Sourcing](https://www.indeed.com/employers/solutions/smart-sourcing) | Filtered proactive discovery, natural-language matching, curated lists and recruiter oversight | Implement candidate-authorized field filters and human-reviewed explanations; natural-language search remains a future contract capability. |
| [Workable Search with AI](https://help.workable.com/hc/en-us/articles/115012750768-Using-Search-with-AI) | Natural-language candidate search across skills, titles, experience and locations, with role-based availability | Implement bounded structured search first; no external profiles, AI credits or live provider. |
| [Zoho Recruit hiring pipelines](https://help.zoho.com/portal/en/kb/recruit/talent-management/hiring-pipeline/articles/managing-hiring-pipelines) | Configurable stages, status history, comments and job-specific pipeline views | Implement explicit allowed transitions, revisions, notes and event history; keep optional stages skippable. |
| [Zoho Recruit features](https://www.zoho.com/recruit/key-features.html) and [dashboards](https://help.zoho.com/portal/en/kb/recruit/analytics/dashboards/creating-dashboards/articles/creating-dashboards) | Candidate matching, real-time pipeline reports and recruiter productivity metrics | Implement rules-based matching and event-derived tenant analytics with documented denominators; no predictive outcomes. |

Competitive opportunity: BillionJobs can differentiate through candidate-controlled disclosure, purpose-specific immutable application snapshots, assignment-specific access, explainable unknown-aware matching, human-only decisions and a provider-independent AI boundary. EP-08 deliberately excludes autonomous screening, protected/proxy attributes, external outreach and opaque ranking.
