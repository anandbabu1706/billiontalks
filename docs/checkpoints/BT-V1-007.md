# BT-V1-007 — Settings, Notifications & Entitlements

## Account and meeting preferences

- Authenticated accounts can save an IANA time zone, a default meeting duration, and a default guest-access policy.
- New schedules load those defaults; existing schedules are unaffected.
- In-app meeting-event and invitation-response notifications have independent opt-outs.

## Notifications

- The dashboard shows an unread count and links to the notification feed.
- Owners receive notifications for their schedule creation, updates, cancellation, start/end, and invitation responses.
- Notification reads and read/unread updates are scoped to the authenticated account. Read-all affects only that account.
- Records use unique account/event keys so retried event writes do not duplicate alerts. Responses are private and not cacheable.

## Entitlements

- Existing and newly accessed accounts receive an active `BASELINE` entitlement record.
- Entitlements are informational only; no existing feature is restricted. No billing, pricing, or payment integration is configured.

The additive D1 migration is `0007_settings_notifications_entitlements.sql`. Settings rows for accounts created after migration are initialized on authenticated access. No prior meeting, invitation, or account records are rewritten.
